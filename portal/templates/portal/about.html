About University Student Portal

The University Student Portal is a web-based application designed to efficiently manage student information in a structured and organized manner.

Our Mission

Our goal is to simplify student record management by providing an intuitive interface for adding, editing, viewing, and deleting student data. This portal ensures quick access to important academic information.

Features

  • Add new student records
  • Edit existing student details
  • Delete student records securely
  • View complete student information
  • Responsive and user-friendly interface

Technologies Used

  • Django (Python Web Framework)
  • HTML5 & Bootstrap 5
  • CSS for styling
  • SQLite Database (Django default)

Future Enhancements

  • User authentication & login system
  • Search and filter students
  • Pagination support
  • Database-backed permanent storage
