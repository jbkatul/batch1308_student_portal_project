About Student Portal

A simple, lightweight application to manage records.

Project Overview

this Student Portal by Kiran Academy is a demonstration of a basic web application built using Django. It allows users to add, view, and search student records without the need for a database, utilizing in-memory storage instead. The application is designed to be simple and easy to understand, making it an ideal starting point for those new to web development with Django.

Core Features

In-Memory Storage

Data persists in global Python lists while the Django server process is running.

Bootstrap 5 UI

Fully responsive and modern user interface utilizing the latest Bootstrap components.

Search Functionality

Case-insensitive search capabilities to quickly locate specific student records.

Template Inheritance

DRY architecture using Django's powerful template extension system.

Developed as a technical demonstration.
