About Student Portal

A simple and efficient system to manage student information.

Who We Are

The Student Portal is a web application built using Django and Bootstrap. It allows users to add students, view student lists, and check detailed information for each student.

This project is designed to demonstrate how a basic student management system works using Django framework.

Features

Add Students

Easily add new student details into the system.

View Students

See a list of all students in an organized format.

Student Details

Access complete information of each student.
